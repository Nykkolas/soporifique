# Résumé
***level:*** user goal
***title:*** Entrer en hibernation
***user:*** Utilisateur de l'ordinateur
***but:*** Faire entrer l'ordinateur en hibernation quand le niveau de batterie passe sous un seuil

# Contexte
***preconditions:*** 
- Le seuil est défini (UC-01 ou valeur par défaut)
- L'application est lancée et visible dans la barre d'état système
***success guarantee:*** L'ordinateur est en hibernation
***minimal guarantee:*** Si l'hibernation n'est pas possible, une erreur est enregistrée dans un journal lisible par l'utilisateur
